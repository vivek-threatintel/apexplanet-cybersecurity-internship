# Task 1 — Foundations & Environment Setup

## Objective

Build a foundational understanding of cybersecurity concepts and establish a professional cybersecurity lab environment for hands-on practice.

## Topics Covered

- Cybersecurity Fundamentals
- CIA Triad
- Common Threat Types
- Attack Vectors
- Linux Fundamentals
- Networking Fundamentals
- Cryptography
- OpenSSL
- Security Tool Familiarization

## Lab Environment

The practical lab consists of:

- Kali Linux — Security testing workstation
- Metasploitable 2 — Intentionally vulnerable target
- QEMU/KVM — Virtualization platform
- `cyberlab` — Private lab network
- Wireshark — Network traffic analysis
- Nmap — Network discovery and scanning
- Burp Suite — Web application security testing
- Netcat — Network troubleshooting and testing
