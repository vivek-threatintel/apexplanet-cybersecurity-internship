# Cybersecurity Basics

## 1. CIA Triad

The CIA Triad is a fundamental model used in cybersecurity to describe three core security objectives: Confidentiality, Integrity, and Availability.

### Confidentiality

Confidentiality ensures that information is accessible only to authorized individuals, systems, or processes.

**Example:** Encryption and access controls can prevent unauthorized users from accessing sensitive information.

### Integrity

Integrity ensures that information remains accurate, complete, and protected from unauthorized modification.

**Example:** Cryptographic hashes can be used to detect whether a file has been modified.

### Availability

Availability ensures that systems, services, and information remain accessible to authorized users when required.

**Example:** Redundant infrastructure, backups, and DDoS protection can help maintain availability.

---

## 2. Common Threat Types

### Phishing

Phishing is a social engineering technique in which attackers use fraudulent messages, emails, websites, or other communications to trick victims into revealing sensitive information or performing malicious actions.

### Malware

Malware is malicious software designed to compromise, damage, disrupt, or gain unauthorized access to computer systems.

Common examples include:

- Virus
- Worm
- Trojan
- Spyware
- Ransomware

### Distributed Denial-of-Service (DDoS)

A Distributed Denial-of-Service attack attempts to make a service unavailable by overwhelming it with a large volume of requests or network traffic from multiple systems.

### SQL Injection

SQL Injection is a web application vulnerability in which untrusted input is improperly incorporated into SQL queries. An attacker may exploit this weakness to access or manipulate database information.

### Brute Force

A brute-force attack attempts to discover valid credentials by systematically trying many possible passwords or authentication combinations.

### Ransomware

Ransomware is a type of malware that prevents access to data or systems, commonly by encrypting files, and may demand payment from the victim.

---

## 3. Attack Vectors

### Social Engineering

Social engineering involves manipulating or deceiving people into revealing information or performing actions that can compromise security.

**Example:** An attacker impersonating an IT administrator and asking an employee to reveal credentials.

### Wireless Attacks

Wireless attacks target wireless networks, devices, or communications by exploiting weaknesses in their configuration, authentication, or protocols.

**Example:** Attempting to gain unauthorized access to an improperly secured wireless network.

### Insider Threats

An insider threat originates from an individual who has legitimate access to an organization's systems, network, or information.

Insider threats can involve:

- Malicious employees
- Negligent users
- Compromised accounts

## 4. Security Objectives and Threat Summary

| Category | Description |
|---|---|
| Confidentiality | Prevent unauthorized access to information |
| Integrity | Prevent unauthorized modification of information |
| Availability | Ensure systems and services remain accessible |
| Phishing | Deceive users to obtain information or trigger actions |
| Malware | Malicious software used to compromise systems |
| DDoS | Disrupt service availability |
| SQL Injection | Exploit unsafe handling of database input |
| Brute Force | Attempt many credential combinations |
| Ransomware | Restrict access to data or systems |
| Social Engineering | Manipulate people to compromise security |
| Wireless Attacks | Target wireless networks or communications |
| Insider Threats | Threats involving legitimate access |

## Key Takeaways

- The CIA Triad provides three fundamental cybersecurity objectives.
- Threats can target people, applications, networks, systems, and data.
- Attack vectors describe the paths or methods used to compromise a target.
- Effective security requires multiple layers of controls rather than relying on a single defensive mechanism.
